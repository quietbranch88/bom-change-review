## 新程式接在哪裡

[supplemental_model.py](../supplemental_model.py)讀取第五課已保存的 source.json，只把補充原文、來源 ID／指紋及擷取規則送進請求。示範草稿、模板、期望答案與原 E01 review 都不進 prompt。

預定流程：原文 → 模型請求 → 回傳格式／成本／引文檢查 → 原有 intake 驗證 → 另存 model_output 待審快照。`model_output` 仍是來源聲明，不是身分驗證或人工核准；語意與限制完整性仍為 unverified，原 follow-up 不變。

請求沿用 mistralai/ministral-3b-2512、mistral/zdr、temperature=0、max_tokens=2048、strict JSON schema、無工具／插件／fallback。型別、許可分類、constraints、open_questions 與引文由模型提出，程式另外驗證來源及引文。

官方依據：[Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs)說明 response_format/json_schema 及 require_parameters；端點支援仍需預檢，strict 也不取代本機或語意覆核。[Limits](https://openrouter.ai/docs/api/reference/limits)說明 GET /key 可讀取金鑰額度。這些文件不是本輪模型成功證據。

## 可以安全查看什麼

```powershell
rtk uv run --no-project --python 3.13 python supplemental_model.py plan
```

這個一次性入口綁定已授權的本機來源快照指紋與固定輸出目錄，不是任意文字付費工具。全新 checkout 沒有該 ignored source 檔，會回固定錯誤；不能為了啟動而更改授權指紋或搬用其他來源。
